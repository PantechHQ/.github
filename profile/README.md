# PantechHQ

**Tecnologia a serviço da educação inclusiva.**

A PantechHQ é a organização responsável pelo desenvolvimento do **Ludicos**, um Trabalho de Conclusão de Curso (TCC) voltado à criação de uma plataforma de aprendizagem inclusiva.

## 🎓 Sobre o projeto

O Ludicos busca tornar a educação mais acessível, especialmente para pessoas com Transtorno do Déficit de Atenção com Hiperatividade (TDAH) e Transtorno do Espectro Autista (TEA).

A plataforma reúne recursos educacionais, cursos, aulas e ferramentas interativas em uma experiência de aprendizagem que considera diferentes necessidades. Sua proposta está alinhada ao **Objetivo de Desenvolvimento Sustentável 4 (ODS 4)** da Organização das Nações Unidas (ONU), dedicado à educação de qualidade, inclusiva e equitativa.

## 🛠️ Tecnologias

O projeto utiliza tecnologias modernas para desenvolver, testar e executar uma aplicação full-stack.

| Área | Tecnologias |
|---|---|
| Frontend | Next.js, React, TypeScript e Tailwind CSS |
| Backend | C#, ASP.NET Core e .NET 10 |
| Banco de dados | PostgreSQL e Entity Framework Core |
| Testes | Vitest, Testing Library e xUnit |
| Automação | GitHub Actions e Lefthook |
| Infraestrutura | Podman, Podman Compose e Caddy |

## 🧩 Engenharia de software

Além das funcionalidades educacionais, o desenvolvimento considera aspectos importantes da engenharia de software, incluindo:

- **Qualidade:** testes automatizados e integração contínua.
- **Segurança:** autenticação, proteção de credenciais e validação de dados.
- **Manutenibilidade:** separação entre frontend, backend e infraestrutura.
- **Reprodutibilidade:** versões controladas de ferramentas e dependências.
- **Implantação:** aplicações conteinerizadas e configuração de ambiente.

## 📚 Natureza acadêmica

O Ludicos é desenvolvido como Trabalho de Conclusão de Curso (TCC). Suas funcionalidades, decisões arquiteturais e práticas de desenvolvimento fazem parte do processo de concepção e implementação da solução proposta.

O projeto tem como propósito explorar como a tecnologia pode contribuir para experiências de aprendizagem mais inclusivas e acessíveis.
